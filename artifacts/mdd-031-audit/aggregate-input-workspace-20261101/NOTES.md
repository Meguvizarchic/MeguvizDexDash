# Aggregate materialization and workspace correction

- Observation: the real-session red test returned success for `MIN(?) IS NOT NULL` with a 4096-unit TEXT argument and a 64-step query budget. `red/` records the failing expectation, not an engine test pass. `red-before.json` and `red-after.json` identify its unchanged inputs.
- Cause: aggregate callbacks decoded and retained variable-length input without the existing charged argument materialization; the final Rust SQLite carrier was also a concurrent uncharged copy.
- Correction: decode under the same step and workspace controls as scalar callbacks; retain the selected value's reservation until replacement or finalization; reserve the final carrier while the accumulated input is still live and keep its lease through the existing rusqlite `ToSql` wrapper. Allocation failure for SQLite output carriers is reported as a quota error. SQLite's own copy, allocation overhead and RSS remain outside these logical reservations.
- Failed intermediate approach: the first `aggregate_` compile failed because the lease's dynamic keepalive is not automatically `UnwindSafe` (`green/`). A local `AssertUnwindSafe` wraps only the moved-or-dropped aggregate lease; it does not alter the shared reservation type. This was a compiler failure, not a runtime result.
- Targeted results: `green-retry/` records `cargo test --locked -p mdd-sql aggregate_ -- --nocapture`, 14 passed, including four new tests. `green-udf/` records four existing scalar-materialization tests passed. `green-tosql/` records one existing wrapper callback-lifetime test passed. The three sets have no overlapping test names. `green-after.json` records the SQL, query/facts entry point, lockfile and test executable identities after those runs. The separate wrapper test does not directly observe an aggregate callback's lease.
- Limits: these are Windows debug-build focused tests; no full-suite, independent host corpus, cross-platform, performance, release or replacement qualification is claimed. Output work is charged before synchronous encoding, not as proof of preemption within the encoding loop. Raw logs contain local paths and must be sanitized before public publication.
