# MeguvizDexDash 图标

来自 Meguviz 图标包（DETAIL REFINEMENT 07，2026-11-06），由同一套 64×64 母版导出，不要单独手改这里的文件；
需要调整时改图标包的母版后重新导出。

| 文件 | 用途 |
|---|---|
| `MeguvizDexDash.svg` | 透明背景双色（深紫 `#4B3F63`、珊瑚橙 `#EF927A`） |
| `MeguvizDexDash-mono.svg` | 单色 |
| `MeguvizDexDash-inverse.svg` | 深色背景用的反白与珊瑚 |
| `MeguvizDexDash-512.png`、`MeguvizDexDash-128.png` | 透明 PNG |

本仓库不含 Android 应用，未并入启动图标资源；图标包提供的自适应启动图标资源名为 `@mipmap/ic_meguviz_dex_dash`
（API 33 起带主题单色层），后续新增示例 app 时可从图标包 `android/res/` 合并。
